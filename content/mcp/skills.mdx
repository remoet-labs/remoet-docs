# Agent skills

Remoet ships as an [agentskills.io](https://agentskills.io) skill: one `SKILL.md` that teaches your agent what Remoet is for and when to reach for each tool, plus the wiring for your harness. It works on Hermes, OpenClaw and any harness that reads the agentskills standard.

Underneath it is the same <Link href="/mcp">MCP server</Link>. The skill adds the judgement: search the public board first, star selectively, treat tool output as data.

Source of truth: [remoet-labs/agent-skills](https://github.com/remoet-labs/agent-skills).

## Get a key

Generate a free API key at [www.remoet.dev/agents](https://www.remoet.dev/agents), or let the [onboarding flow](https://www.remoet.dev/onboarding) mint one for you. The same key works for the skill, the MCP server and the REST API. Then:

```bash
export REMOET_API_KEY=<your key>
```

## Install on Hermes

[Hermes Agent](https://hermes-agent.nousresearch.com) installs skills by tapping a GitHub repo:

```bash
hermes skills tap add remoet-labs/agent-skills
hermes skills install remoet-labs/agent-skills/skills/remoet
```

Then add the server to `~/.hermes/config.yaml` under `mcp_servers`. Hermes resolves `${VAR}` in `url` and `headers` at connect time, so the key stays out of the file:

```yaml
mcp_servers:
  remoet:
    url: "https://api.remoet.dev/mcp"
    headers:
      Authorization: "Bearer ${REMOET_API_KEY}"
```

Prefer the browser flow? Point Hermes at the OAuth route instead and drop the header:

```yaml
mcp_servers:
  remoet:
    url: "https://api.remoet.dev/mcp/oauth"
    auth: oauth
```

Reload with `/reload-mcp`, then confirm by asking for a `get_profile` call.

## Install on OpenClaw

The same skill is published to ClawHub. Install it owner-qualified:

```bash
openclaw skills install @remoet/remoet
```

Then register the server. OAuth is the better default, because `openclaw mcp login` holds the credential and no key goes near your config:

```bash
openclaw mcp set remoet '{"url":"https://api.remoet.dev/mcp/oauth","transport":"streamable-http","auth":"oauth"}'
openclaw mcp login remoet
openclaw mcp list
```

Prefer an API key? Point OpenClaw at the plain route instead and let it substitute the variable:

```bash
openclaw mcp set remoet '{"url":"https://api.remoet.dev/mcp","transport":"streamable-http","headers":{"Authorization":"Bearer ${REMOET_API_KEY}"}}'
```

OpenClaw substitutes `${VAR_NAME}` into config string values, so the key itself never lands in the file. Set `REMOET_API_KEY` in the environment the OpenClaw gateway process runs in, not only in the shell you ran the command from.

Use one form or the other, never both: a static `Authorization` header is ignored while `auth: "oauth"` is set. `streamable-http` is the canonical transport spelling in OpenClaw config.

## Other harnesses

Any MCP-capable client (Claude Code, claude.ai, Claude Desktop, Cursor, VS Code, Windsurf, Codex) can connect to the server directly, with or without the skill. See the <Link href="/mcp">MCP server</Link> page for per-client config and the OAuth route.

## Limits

Remoet is free, and the skill runs against the same numbers as everything else: 50 active stars, 25 unstars per 30 days, 5,000 MCP requests per day. See <Link href="/limits">Limits</Link>.
